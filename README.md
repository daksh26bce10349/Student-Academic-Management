# Student Academic Management & Performance Analyzer

## 1. Overview

The Student Academic Management & Performance Analyzer is a
Python-based application designed to manage student academic
records and analyze their performance.

The project allows the user to add and manage student details,
enter subject marks, calculate percentages and grades, analyze
student and class performance, and generate academic reports.

Student records are stored using JSON so that the information can
be saved and loaded when the program is used again.

## 2. Features

- Add student details
- View all students
- Search for a student
- Update student details
- Delete student records
- Enter and update subject marks
- View student marks
- Calculate student percentage
- Calculate student grade
- Find strongest and weakest subjects
- Analyze class average
- Generate individual student reports
- Generate class reports
- Save and load student data using JSON
