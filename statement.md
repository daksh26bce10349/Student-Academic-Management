# Student Academic Management & Performance Analyzer

## 1. Problem Statement

Managing student academic records manually can be time-consuming
and can make it difficult to organize student information, marks
and performance results.

Students and teachers may need to maintain records and calculate
academic performance such as percentages, grades and class
averages.

The Student Academic Management & Performance Analyzer provides
a simple Python-based solution for managing student academic
records and analyzing their performance.

## 2. Scope of the Project

The project focuses on basic academic record management and
performance analysis.

The system covers:

- Student information management
- Subject marks management
- Percentage calculation
- Grade calculation
- Student performance analysis
- Class performance analysis
- Student report generation
- Class report generation
- Saving and loading student records using JSON

The project is designed as a simple menu-driven application and
does not include advanced database systems or graphical user
interfaces.

## 3. Target Users

The main target users of this project are:

- Students who want to manage and analyze their academic records
- Teachers who want to maintain basic student performance records
- Academic users who need simple student performance reports

## 4. High-Level Features

### Student Management

The system allows users to:

- Add students
- View students
- Search students
- Update student information
- Delete students

### Marks Management

The system allows users to:

- Enter subject marks
- Update marks
- View marks

### Performance Analysis

The system can:

- Calculate percentage
- Calculate grade
- Identify strongest subject
- Identify weakest subject
- Calculate class average

### Report Generation

The system can generate:

- Individual student reports
- Class performance reports

### Data Storage

Student records are stored and retrieved using a JSON file.
This allows academic data to be retained between program runs.
